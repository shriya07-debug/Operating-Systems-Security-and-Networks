# Lab 3: Investigating Process Lifecycles and OS Interaction

## Tasks

### Task 1: Long-Running Process
Demonstrates a process running for 30 seconds using `sleep()` and monitoring it using `ps`.

### Task 2: Process Identity
Demonstrates how to obtain the Process ID (PID) and Parent Process ID (PPID) using `getpid()` and `getppid()`.

### Task 3: Exit Codes
Demonstrates how a C program returns an exit status to the operating system using `return 0` for success and `return 1` for failure.

### Task 4: Standard I/O Streams
Demonstrates standard input and output using `scanf()` and `printf()`.

### Task 5: Conditional Execution and Termination
Demonstrates conditional execution, process identification, and exit codes based on user input.

## Technologies
- C
- Linux
- GCC
- Linux process management commands
